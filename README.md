# Kiez Kings – Berlin

Ein GTA-artiges Open-World-Spiel im Browser, das in Berlin spielt (Draufsicht, reines HTML5/JavaScript, keine Abhängigkeiten).

**Spielen:** `index.html` im Browser öffnen (oder `python3 -m http.server` im Ordner starten und `http://localhost:8000` aufrufen).

## Inhalt
- Berlin mit Spree, Tiergarten, Brandenburger Tor, Reichstag, Berliner Dom, Fernsehturm am Alex, East Side Gallery, Checkpoint Charlie, Potsdamer Platz, Tempelhofer Feld, Charité und Schloss Charlottenburg
- 12 Bezirke und echte Straßennamen in der Anzeige
- Autos klauen und fahren (Kompaktwagen, Trabi, Taxi, Transporter, Sportwagen, Linienbus, Streifenwagen), Driften mit der Handbremse
- Verkehr mit Rechtsverkehr, Fußgänger, Polizei mit Fahndungssternen und Martinshorn
- 5 Story-Missionen, Taxi-Nebenjob, Lackierereien (Fahndung weg + Reparatur)
- 3 Lidl-Filialen: Kong Strong, Nuss-Nougat-Gipfel, Brezeln, Verbandskasten, Werkzeugkoffer u. v. m.
- Tag-/Nacht-Wechsel mit Straßenlaternen und Scheinwerfern
- Touch-Steuerung fürs Handy, Spielstand wird im Browser gespeichert

## Steuerung
| Taste | Aktion |
|---|---|
| WASD / Pfeile | Laufen / Fahren |
| E | Ein- und Aussteigen, Auto klauen |
| Leertaste | Handbremse |
| Shift | Rennen |
| K | Stadtplan |
| H / M / P | Hupe / Ton / Pause |
| G | Grafik hoch / mittel / niedrig |
